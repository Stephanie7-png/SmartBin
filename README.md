# SmartBin — Projet de Poubelle Intelligente Connectée

SmartBin est une solution IoT innovante permettant de surveiller en temps réel le niveau de remplissage des déchets grâce à des capteurs intelligents connectés.

Le projet vise à améliorer la gestion des déchets dans les espaces publics et privés tout en réduisant les coûts de collecte et l'impact environnemental.

### Objectifs
* **Réduire les débordements** des poubelles.
* **Optimiser les tournées** de collecte logistique.
* **Superviser les poubelles** à distance via un tableau de bord.
* **Participer au développement** des Smart Cities.
* **Moderniser la gestion** globale des déchets.

### Architecture Technique
* **Backend :** Python Flask API avec gestion des accès par rôles (Admin / Agent) et notifications d'alertes logistiques par mail.
* **Frontend :** Interface Web adaptative temps réel structurée par Personas (Collectivités urbaines & Établissements privés).
* **Simulateur :** Script autonome de génération de flux de déchets pour les tests de charge.
